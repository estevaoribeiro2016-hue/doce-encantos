# V56.1 — Correção de bairros

Esta versão corrige bancos antigos que ainda possuem a coluna obrigatória `neighborhood`.

## Instalação recomendada
1. Execute `CORRECAO-BAIRROS-V56.1.sql` no SQL Editor.
2. Depois execute o arquivo completo `DOCE-ENCANTO-BANCO-COMPLETO-V56.sql`.
3. Publique os arquivos do site normalmente.

Nenhum pedido, estoque ou bairro existente é apagado.
