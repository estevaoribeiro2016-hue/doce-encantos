# Doce Encanto V56.8

Correção definitiva da validação de e-mail no Pix.

- E-mail do cliente agora é opcional.
- Espaços invisíveis e caracteres comuns copiados do celular são normalizados.
- Quando o e-mail não for válido ou estiver vazio, o backend gera um e-mail técnico exclusivo para o pedido.
- O cliente não fica bloqueado por validação de e-mail.
- Base preservada da V54/V56.7.
