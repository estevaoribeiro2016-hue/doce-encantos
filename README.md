# Doce Encanto v12

Site estático pronto para Vercel/GitHub.

## Estrutura correta no GitHub
Os arquivos precisam ficar na raiz do repositório:

- index.html
- assets/
- cliente/
- empresa/
- admin/
- README.md

Não envie uma pasta por fora contendo esses arquivos. Envie o conteúdo de dentro da pasta.
