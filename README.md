# Doce Encanto V43 — Carrinho e Estoque Inteligente

Atualizações principais:

- Corrigido botão **Finalizar pedido**.
- Ao finalizar, o pedido é criado em **Pedidos Pendentes** da central da empresa.
- Estoque só é descontado quando o pedido é finalizado.
- Se o pedido for cancelado, o estoque volta automaticamente.
- Botões **+** e **-** do resumo do pedido corrigidos.
- Promoção agora pode aumentar/diminuir a quantidade no carrinho.
- Promoções respeitam o estoque dos sabores escolhidos.
- Trufas sem estoque aparecem como indisponíveis.
- Cliente não consegue finalizar pedido acima do estoque disponível.
- Painel de estoque com quantidade por sabor.
- Histórico de movimentação do estoque: entrada, saída, pedido e cancelamento.

## Como publicar

1. Extraia o ZIP.
2. Entre dentro da pasta extraída.
3. Selecione todos os arquivos e pastas de dentro.
4. Envie para o GitHub na raiz do repositório.
5. Aguarde a Vercel atualizar.
